# Castle Aldurn — حزمة البرومبتات (المرحلة 0)

قلعة ألدُورن: قلعة أوروبية حقيقية (High Medieval) بطابع Norman → Early English Gothic مع **قصر/قاعة كبرى** في الفناء الداخلي — الهدف النهائي: **موديل 3D قابل للعب في MTA:SA** بملفات `DFF + TXD + COL + LOD` ونظام **Day/Night**، **مطابق للصورة المرجعية** التي سترفعها.

> ### ⚠️ أوقفتُ التنفيذ عند هذه النقطة بانتظار شيئين — كما طلبت
> 1. **البرومبتات** (ملفات هذا المستودع) — سلّمها للمصمم/المولّد، وانتظر النتيجة.
> 2. **الصور المرجعية + الخامات** — ارفعها إلى GitHub في المجلدات المحددة أدناه، وقل لي فقط: **«تم الرفع»**، وسأتابع تلقائيًا من غير أي سؤال إضافي.
>
> **لا يوجد أي ملف صورة في المستودع حاليًا** — لم يصل أي مرفق إلى بيئة العمل، ولهذا توقفت ولم أخترع تصميمًا من عندي (لأن أي تخمين سيُخالف قاعدة "المرجع هو مصدر الحقيقة").

## 1️⃣ الخطوة الأولى — اطلب الصورة المرجعية بهذا البرومبت

**انسخ البرومبت الرئيسي من [`docs/02_image_prompts_en.md`](docs/02_image_prompts_en.md) القسم 0** (Master Prompt) واطلبه من أي مولّد صور، ثم استخدم الصورة الناتجة كمرجع (Image Reference / ControlNet) لتوليد باقي الأوراق B → I.

**الحد الأدنى المقبول:** الأوراق **A** (بطولي) + **B/C/D** (مساقط) + **E** (مخطط أسطح) + **I** (الظلّي).
لكن **كلما زادت الأوراق زادت دقة المطابقة** — خصوصًا `Silhouette` (ورقة I) لأنني أقيس منها النسب والارتفاعات قبل البناء.

### أين ترفع الصور؟
```
saradztn/castle
└── reference/
    ├── ref_A_hero.png
    ├── ref_B_elevation_south.png
    ├── ref_C_elevation_east.png
    ├── ref_D_elevation_north.png
    ├── ref_E_plan_roof.png
    ├── ref_F_courtyard.png
    ├── ref_G_night.png
    ├── ref_H_details.png
    └── ref_I_silhouette.png
```
> الأسماء أعلاه اختيارية — أي أسماء واضحة تكفي. الأهم أن تكون في مجلد **`reference/`**.
> وإن أردت الأسهل: **أرفق الصور مباشرة في الدردشة هنا** وسأعمل عليها فورًا.

## 2️⃣ الخطوة الثانية — ولّد الخامات بنفسك (PBR 4K) وارفعها

الخامات **لا أريد توليدها بنفسي** — سأستخدم التي تولّدها أنت، كما اتفقنا. اختر **Tier 1** كحد أدنى للبدء (12 خامة × 5 خرائط).

### أماكن الرفع
```
saradztn/castle
└── textures/
    └── src/
        ├── stone_ashlar_wall_albedo.png
        ├── stone_ashlar_wall_normal.png
        ├── stone_ashlar_wall_roughness.png
        ├── stone_ashlar_wall_ao.png
        ├── stone_ashlar_wall_height.png
        ├── roof_slate_albedo.png
        ├── ...
        └── (كما في docs/textures.manifest.json)
```
- التسمية **حرفيًا**: `<id>_<map>.png` — الأسماء في ملف الـmanifest (`albedo`, `normal`, `roughness`, `ao`, `height`, وأضف `_alpha` عند الحاجة).
- القنوات: **Albedo = sRGB بلا إضاءة أو ظلال محفورة**، والباقي **Linear**، والـNormal بصيغة **OpenGL (+Y up)**.
- التكرار: **Seamless** على الحواف الأربعة (إلا ما هو معلّم `non_tiling`).
- مقياس البلاطة (`tile_m`) مذكور لكل خامة — مهم جدًا لتطابق حجم الحجر مع الصورة.

## 3️⃣ ماذا سيحدث بعد «تم الرفع»؟ (خط الأنابيب الذي سأنفّذه)

```
reference/  →  تحليل بصري ومعماري (Silhouette, النسب, مواضع الأبراج, البوابة, الأسقف, النوافذ)
            →  بناء هندسي دقيق بالأمتار (سور 72×54، 4 أبراج زوايا، بيت بوابة، حصن 16×16، قصر 36×15، كنيسة)
            →  تفاصيل معمارية (ميزابيات، شرفات، نوافذ مقوّسة، مداخن، بئر، سلالم، جسر متحرك، خندق جاف)
            →  UV يدوية + خاماتك عالية الجودة (4K → تحسين/ضغط لـTXD)
            →  DFF + TXD + COL + LOD (3 مستويات)
            →  نظام Day/Night حقيقي لـMTA (إضاءة + شيدر + ليل/نهار)
            →  مقارنة بصرية نهائية على 11 نقطة مقابل المرجع، وتعديل أي انحراف
```

# Castle & Palace — مدينة القلعة الساحلية (MTA:SA)

> **المشروع:** إعادة إنشاء **مدينة قلعة ساحلية كاملة** على جرف صخري شبه جزيرة — بقصر/كاتدرائية متوّج بالأبراج على القمة، ثلاث حلقات أسوار، ست مصاطب مدينة، مرفأ، جسر حجري مقوّس، شلالان — كـ**موديل 3D حقيقي قابل للعب في MTA:SA** (`DFF + TXD + COL + LOD` + إضاءة نهار/ليل + 14 داخلية).
>
> **الصورة المرجعية المرفقة هي مصدر الحقيقة الوحيد.** لا اختراع، لا إعادة تفسير: نفس التكوين، نفس عدد الأبراج، نفس النسب، نفس الخامات، نفس الإحساس البصري.

## 🎯 البرومبت الرئيسي الجديد (انسخه الآن)

> كامل + قابل للنسخ من [`docs/02_image_prompts_en.md`](docs/02_image_prompts_en.md) — القسم 0. أول سطر منه:

```text
Cinematic photorealistic aerial view of a colossal medieval castle-city built on a rocky coastal promontory, real late-medieval to early-Renaissance architecture with a fantasy-realistic sense of scale, NOT a cartoon and NOT a single castle on flat ground. ... (تابع الملف)
```

### ما يغطيه البرومبت (مطابقة عنصر بعنصر)
قصر/كاتدرائية القمة (برج مركزي 95 م + 6 أبراج مخروطية + برجان مستديران + دعامات طائرة + نافذة وردة) · ثلاث حلقات أسوار متتابعة بأبراج ميزابية · بيت بوابة رئيسي بقوس وبنتين · بوابة بحرية · **ست مصاطب مدينة** بـ320 مبنى وأزقة درجية وجسور معقودة وكنيسة ببرج أجراس · **مرفأ** بأرصفة وأخشاب ومخازن ورافعة وسفن شراعية · **جسر حجري مقوّس بـ8 عقود وأكتاف مائية** ينتهي عند بوابة مائية ببرجين · **شلالان كبيران** (≈60/35 م) · حدائق ملكية بنافورة · منارة 34 م · جبال ثلجية وضباب وطيور · إضاءة ذهبية غروب · وخامات المرجع بالـHex مع الطحالب والملح البحري.

**الحد الأدنى الذي أحتاجه للبدء بالبناء:** الورقة البطهورية (A) + الخريطة المرقّمة (B) + المساقط/السيلويت (F) + التقريبات الأربعة. أما الـ**14 داخلية** فمطلوبة للمرحلة الرابعة.

## 📦 ما أطلبه منك الآن

### الخامات — **كل خامة بصورة مستقلة** (يتولاها الوكيل بالذكاء الاصطناعي)
| # | البند | الحالة |
|---|---|---|
| 1 | الدفعة الأولى: 10 خامات (حجر رملي، غرانيت، حجر بحري مطحلب، جص، رصيف، حصى، أردواز، قرميد، شينجل خشبي، عوارض بلوط) | ✅ **مُولَّدة ومعالجة** |
| 2 | الدفعات التالية: 28 خامة متبقية (أبواب، جرف، عشب، بحر، رخام، أرضيات، تلبيس جوز، جوخ، سجاد، جلد، حديد، نحاس، زجاج، رايات، decals…) | 🚧 **10 خامات في كل جولة حتى الاكتمال** |
| 3 | صور مرجعية إضافية عالية الدقة (بطهورية/جوية/ليلي/مساقط) — اختياري لكن يُحسّن المطابقة | ⏳ `reference/` |
| 4 | لو أردت توليد أي خامة بنفسك: اسم الملف `<id>_albedo.png` في `textures/src/` ثم قل «تم الرفع» | ⏳ |

**كل خامة تُولَّد وتُعالج آليًا:** اقتطاع مربّع ← Seamless ← Albedo ← **Normal + Roughness + AO** ← لوح معاينة.
(الخرائط المشتقّة لا تُرفع إلى Git لأنها تُولَّد بأمر واحد: `python3 tools/process_textures.py --src textures/src --size 1024 --seamless --derive-pbr --alpha-decals`.)

```
saradztn/castle
├── reference/     ←  الصور المرجعية (A..F) إن رفعتها
├── textures/src/  ←  الخامات: كل خامة في صورة منفصلة  <id>_albedo.png
├── textures/preview/contact_sheet.jpg  ←  معاينة كل الخامات
└── tools/process_textures.py           ←  المعالجة وتوليد الخرائط
```

## 🔧 خط الأنابيب بعد الرفع

```
الصورة المرجعية → تحليل وقياس → بلوك-أوت (مطابقة الظل أولًا) → تفصيل خارجي كامل
→ داخلليات (14) → UV + خاماتك + decals → DFF + TXD + COL → LOD ×4 → نهار/ليل
→ مقارنة بصرية (11 نقطة) → تعديل الانحرافات → تسليم MTA
```

| المرحلة | الحالة |
|---|---|
| تحليل المرجع | ✅ مُنجز |
| حزمة البرومبتات (صور + خامات) | ✅ مُنجزة ومطابقة للمرجع |
| المواصفات التقنية MTA | ✅ مُنجزة |
| الخامات | ⏳ ستولّدها وترفعها |
| بناء الموديل | ⛔ لم يبدأ — بانتظار `textures/src/` + كلمة «تم الرفع» |

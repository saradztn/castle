### 2) مورد MTA — كود كامل (17 ملفًا)
```
mta/castle/
├── meta.xml                     ← تعريف كامل + min_mta_version 1.6
├── shared/config.lua            ← 5 معرّفات موديل + LOD + إضاءة + أوقات + 11 منطقة
├── server/s_time.lua            ← وقت اليوم + مزامنة الإضاءة عالميًا
├── server/s_commands.lua        ← /castletime + /castlegoto
├── client/loader.lua            ← COL→TXD→DFF + سلسلة LOD رباعية + منع التشتيت
├── client/lighting.lua          ← ★ 32 مصدر ضوء حقيقي + دورة نهار/ليل + هالات
├── client/gameplay.lua          ← /castle + 10 مناطق + اسم المنطقة على الشاشة
├── client/hud.lua               ← شاشة تحميل + مؤشر ارتفاع/إضاءة
├── shaders/pointlight.fx        ← ★ إضاءة نقطية: Ambient + Lambert + انحلال مزدوج
├── shaders/glow.fx              ← هالات مشاعل/فوانيس/منارة
├── data/lamps.json              ← 83 موضع ضوء مستخرج من الموديل
├── data/spawns.json             ← 9 نقاط لعب
├── data/parts.json              ← إحصاءات + خطة LOD
└── textures/                    ← 23 خامة جاهزة
```

**كيف تعمل الإضاءة القوية؟**
1. شيدر `pointlight.fx` يُطبَّق على خامات الموديل عبر `engineApplyShaderToWorldTexture` بأنماط `mat_*, stone_*, roof_*…`
2. كل **120ms** يُمرَّر إليه أقرب **32 مصدر ضوء** من أصل 83: `gLightPos[32]` (xyz + المدى) + `gLightColor[32]` + `gLightParams[32]` + `gLightCount`
3. نموذج الإضاءة: **Ambient + Lambert نصف-ناعم + انحلال مزدوج** `att²/(1+0.20d+0.05d²)` + **تشبّع ناعم**
4. أنواع: مشعل (ارتعاش 9Hz) · فانوس شارع · منارة (نبض 1.7Hz)
5. نهارًا: `gAmbient = (0.44,0.46,0.52)` · ليلًا: `(0.05,0.065,0.135)` → تباين درامي حقيقي

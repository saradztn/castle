## 🔀 دمج الفرع
كان على الفرع البعيد عمل موازٍ كامل (`mta/castle/` + شيدر إضاءة نقطية 32 مصدرًا). دُمج بلا فقدان:
- **الشيدر `pointlight.fx` + `glow.fx`** انتقلا إلى المورد الأساسي `mta/shaders/` مع وحدة جديدة **`mta/client/pointlights.lua`**.
- العمل الموازي محفوظ كاملًا في **`alternates/mta_resource_v1/`** + **`alternates/tools_v1_*.py`**.
- خامات الفرع المكرّرة (20.6 MB من نفس الصور) لم تُضاعَف؛ `tools/install_mta_assets.py` يعيد إنشاءها من `textures/src/`.

## ▶️ الأوامر الجاهزة
```bash
python3 tools/build_city.py                                   # بناء المدينة (3.7 ث)
python3 tools/render_preview.py --in build/polys.json --out renders/preview_day.png \
        --mode day --w 1600 --h 1000 --eye "600,-940,190" --target "20,-70,80"

```
